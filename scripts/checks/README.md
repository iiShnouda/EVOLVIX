# API checks

End-to-end checks that call a running SKB server. They create their own data (names carry a
random tag), so they run on a fresh database or on a copy of a real one. Never point them at the
live company server.

| Script | What it checks |
|---|---|
| `places.test.mjs` | Deleting branches and warehouses: an empty one goes with its store and cash boxes; one with documents or stock, the default warehouse, the last warehouse and a branch people belong to stay; own permissions; the server monitor can't be given.; departments added in the warehouses chosen (the others go on as they were), moved, and deleted with their groups when nothing is recorded (one with items stays). |
| `server.test.mjs` | The owner's server pages: the monitor (machine, each part, no paths) and updates (up to date, a new version and its notes read carefully, check / update leave the right word for the updater, busy, timed out, updater not running, retry after a failure, audit); neither for the admin. | `clean.test.mjs` | A company server's first start (`Seed__Demo=false`, empty database): only the owner, one branch, its warehouse, the cash customer; buying and selling work at once. |
| `profit.test.mjs` | Profit and loss: equals the ledger, branches + general = total, warehouses add up to their branch, an expense from a warehouse's box lands on it and one from the main box on general, moving money between boxes changes no profit, sales staff refused. |
| `tree.test.mjs` | Department sub-groups (prefixes, keywords, no two siblings with one name, no loops), item codes following the path, the in-store EAN-13 barcode, search by folded spellings, outlines and a slipped letter, the group filter, label barcodes. |

## Running

```bash
# 1. a server on a throwaway database (Development settings, high rate limits)
ASPNETCORE_ENVIRONMENT=Development ConnectionStrings__Default="Host=localhost;Port=5432;Database=skb_check;Username=skb;Password=..." \
  RateLimit__UserPerMinute=100000 RateLimit__IpPerMinute=100000 RateLimit__LoginPerMinute=100000 \
  ASPNETCORE_URLS=http://localhost:5090 dotnet run --project apps/api/src/SKB.Api

# 2. the checks (Node 22)
BASE=http://localhost:5090/api node scripts/checks/catalog.test.mjs
PGURL=postgres://skb:...@localhost:5432/skb_check node scripts/checks/invariants.mjs

```

`lib.mjs` turns Settings → "hide new places until given" off when the owner signs in (the checks add cash boxes and branches and use them with other people; `story.test.mjs` turns it on to check it). The checks run with Settings → "every sale names its department" off (`PUT /settings {requireDepartment:false}`) and returns allowed at once (`returnAfterHours: 0`); `limits.test.mjs` sets both at its start, so run it first. `invoices.test.mjs` turns the department rule on and off itself.

The seeded demo users are used: `owner@skb.local` (Owner), `mona@skb.local` (Accountant),
`karim@skb.local` (Sales) and `sara@skb.local` (Inventory).
