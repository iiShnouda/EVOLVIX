# SKB — Wholesale Accounting

This Hugging Face Space runs the SKB server (which also serves the web app) in the cloud —
your PC is never involved. It builds from the private GitHub repo at build time using a
read‑only token, so your source stays private.

See `deploy/huggingface/Dockerfile` in the repo for the Space's Dockerfile, and the
"Hugging Face Spaces" section of `HOST-FREE.md` for the step‑by‑step.
